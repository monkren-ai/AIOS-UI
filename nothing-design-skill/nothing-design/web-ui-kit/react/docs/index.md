## 特性

- **克制设计** — 以 Nothing 设计语言为核心，红色点缀、单色字体、极简边框
- **技术精准** — React 19 + TypeScript + Vite + Pure CSS + cva
- **组件丰富** — 60+ 组件覆盖表单、导航、数据展示、反馈、时钟、系统监控
- **主题切换** — 内置暗色/亮色主题，基于 CSS 自定义属性
- **类型安全** — 完整 TypeScript 类型定义，支持泛型和多态
- **可访问性** — 遵循 WCAG 标准，支持键盘导航和 ARIA
